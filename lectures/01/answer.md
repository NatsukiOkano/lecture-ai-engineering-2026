# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：「AIE2026の講座の宿題にある『3レベル』とは何ですか？」と質問したところ、モデルは講座固有の情報を把握しておらず、正確な内容を回答できなかった。

- 用語集の正しい意味と比べて気づいたこと：用語集では、宿題の3レベルは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」と定義されており、いずれか1つに取り組めば宿題は完了すると説明されていた。一方、モデルは講座固有の情報を把握していなかった。このことから、LLMは一般的な知識には回答できても、特定の講座に関する情報を必ずしも持っているわけではなく、正確な回答を得るには外部資料を参照する必要があると分かった。

- 表示できたトークン数（入力 / 出力）：「LoRAとは何ですか？」という質問に対して、入力7トークン、出力662トークンを取得できた。app/ask.py を修正し、Gemini APIのレスポンスに含まれるusage_metadata から入力・出力トークン数を取得して表示した。

## 宿題

- 取り組んだレベル：基礎

- やったこと：
AIE_MODEL 環境変数を使用して、gemini-3.5-flash-lite と gemini-3.5-flash の2つのモデルを切り替えた。
それぞれのモデルに「LoRAとは何ですか？」という同一の質問を3回ずつ送信し、回答内容と出力トークン数を比較した。

- 結果
  - 出力トークン数（1回目、2回目、3回目、平均）
    - gemini-3.5-flash-lite（535、604、550、563）
    - gemini-3.5-flash（773、745、639、719）
  - gemini-3.5-flashの方が平均出力トークンが約156多かった。
    - 両モデルともLoRAの定義やメリットについて説明したが、回答の構成や表現、説明の詳しさには違いが見られた。
    - Flash-Liteでは「付箋」「付け足しパーツ」などの比喩が使われ、Flashでは「透明シート」「プラグイン」などの比喩が使われた。

- 気づき・疑問：
  - 同じモデルに同じ質問を送信しても、回答の表現や説明内容、出力トークン数が変化することが分かった。
  - 今回の実験では、gemini-3.5-flashの方がgemini-3.5-flash-liteよりも平均出力トークン数が多かった。ただし、各モデル3回ずつの実験であるため、今回の結果だけで一般的な傾向を判断することは難しいと考えた。
  - LoRAのファイルサイズについて回答ごとに異なる数値が示されていたことから、LLMが生成した情報の正確性を確認することも重要だと感じた。
